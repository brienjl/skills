# skills
My useful skills when I partner with LLMs in Codex, Claude, etc.

## Planning Skills
### value-wayfinder
* top level planning for large efforts
* use for planning large ideas and creating a roadmap that's focused on the customer and minimal viable increments

### plan-it-through
* usually use with plan-it-through-with-docs
* select an item from the value-wayfinder tickets and tracking and start planning what to build and how
* also calls domain-modeling to create an ADR

### research
* can be used whenever, but can be used to deep dive research a topic using source materials as context
